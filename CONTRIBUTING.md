# Mitwirken

Rückmeldungen sind willkommen, besonders zu falsch bewerteten Anzeigen, zu Barrieren und zu Fehlern beim Bauen.

- **Fehler und Barrieren:** als Issue, mit den Vorlagen „Fehler“ oder „Barriere“. Hilfreich sind die Seite, der Browser und gegebenenfalls das Hilfsmittel.
- **Falsch bewertete Anzeige:** als Issue mit dem Link zur Anzeige und der erwarteten Einstufung.
- **Sicherheitslücken:** nicht als Issue, sondern vertraulich, wie in [`SECURITY.md`](SECURITY.md) beschrieben.
- **Pull Requests:** Die Prüfungen aus [`AGENTS.md`](AGENTS.md) müssen bestehen, die Regeln dort gelten auch für Menschen. Größere Änderungen bitte vorher als Issue besprechen.

Beiträge stehen unter derselben Lizenz wie das Projekt, der EUPL-1.2.

# Contributing

Feedback is welcome, especially on wrongly rated job ads, accessibility barriers and build errors. Report bugs and barriers as an issue using the templates; report vulnerabilities privately as described in [`SECURITY.md`](SECURITY.md). Pull requests must pass the checks listed in [`AGENTS.md`](AGENTS.md); please discuss larger changes in an issue first. Contributions are licensed under the EUPL-1.2, like the project.
